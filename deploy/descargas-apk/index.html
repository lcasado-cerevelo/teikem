Cómo instalar

  1. Toca Descargar. Chrome avisará "El archivo podría ser dañino" ("File might be harmful") — es el aviso estándar para TODO archivo de instalación (APK), no significa que haya un problema. Toca "Descargar de todos modos" ("Download anyway").
  2. Cuando termine, abre el archivo descargado (barra de notificaciones o carpeta Descargas).
  3. La primera vez, el teléfono dirá que no tiene permiso para instalar aplicaciones desconocidas de esta fuente. Toca "Ajustes" ("Settings"), activa "Permitir de esta fuente" ("Allow from this source") y regresa con el botón atrás — la instalación continúa sola. Esto se hace una sola vez.
  4. Si Google Play Protect muestra "App bloqueada" / "App blocked", es normal: la app no se distribuye por Play Store y Google no la reconoce. Toca el enlace pequeño "Instalar de todos modos" ("Install anyway"). OJO: el botón grande "Entendido" ("Got it") CANCELA la instalación — no lo uses.
  5. Si ya tenías la app, se actualiza encima sin perder tu configuración ni tus datos. No la desinstales antes.
